# ![Titanite logo](./src/assets/Titanite.png)

A project built to let an admin manage and toggle smart devices around a house, or just let regular guests view them

![Project Screenshot](./src/assets/Mission6.png)

Features include:
- User authentication with login and component protection
- Separate admin and guest functionalities

Built with:
- JavaScript (ES6)
- React
- HTML
- CSS
- Bootstrap
